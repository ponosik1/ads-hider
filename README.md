# Скрыть рекламу в Яндексе

Расширение Chrome (Manifest V3). Прячет из выдачи рекламные публикации
(«Промо» / «Реклама») и промо-виджеты вроде «Установите Яндекс Браузер».

## Установка

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку `ads-hider`.
3. Открыть/обновить `yandex.ru/search`.

## Что скрывается

### 1. Рекламные публикации

Пометка в разметке Яндекса — иконка рядом с доменом:

```html
<span class="Icon2 Icon2_mask eLQ4yFCKJcFk-Icon" aria-label="Промо" role="img"></span>
```

`content.js` ищет `aria-label` = «Промо»/«Реклама»/«Спонсор»/«Sponsored», плюс короткие
текстовые пометки «Реклама» (другой вариант вёрстки), поднимается от пометки до карточки
(ближайший `li` / `.Organic` / `.serp-item` со ссылкой и меньше 4000 символов текста)
и скрывает её.

### 2. Промо-кнопки («Установите Яндекс Браузер»)

```html
<a class="Button DistributionButton DistributionLinkBro" aria-label="Установите Яндекс Браузер">
```

Ищутся элементы с классами `Distribution*` и `aria-label` про Яндекс Браузер, от них
поднимаемся до ближайшего контейнера с `Distribution` в классе и скрываем его целиком.

Следит за подгрузкой выдачи и новыми страницами через MutationObserver.

## Проверка

`tests/ad.html` — копии присланной разметки: рекламная карточка с иконкой «Промо»,
карточка с текстовой пометкой «Реклама», промо-кнопка браузера и обычный результат.

```bash
npm i jsdom            # в любой временной папке
NODE_PATH=<папка>/node_modules node ads-hider/tests/check.js
```

Ожидаемый вывод:
`{"ad1":true,"ad2":true,"promoBlock":true,"organic1":false,"listUntouched":true}`

## Ограничения

- Скрываются карточки в списке выдачи и промо-виджеты `Distribution*`. Другие блоки,
  размеченные иначе, не трогаются — для них нужен свой HTML.
- Если Яндекс поменяет `aria-label` или классы, правило перестанет срабатывать:
  поправить `AD_WORD` / `PROMO_SELECTOR` в `content.js`.

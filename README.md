# Скрыть рекламу в Яндексе

Расширение Chrome (Manifest V3). Прячет из выдачи публикации с пометкой
«Промо» / «Реклама» — вместе с заголовком и сниппетом, а не только иконку.

## Установка

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку `ads-hider`.
3. Открыть/обновить `yandex.ru/search`.

## Как определяется реклама

В реальной разметке Яндекса пометка — иконка рядом с доменом:

```html
<span class="Icon2 Icon2_mask eLQ4yFCKJcFk-Icon" aria-label="Промо" role="img"></span>
```

`content.js`:

1. ищет элементы с `aria-label` = «Промо»/«Реклама»/«Спонсор»/«Sponsored» (иконка)
   и короткие текстовые пометки «Реклама» (другой вариант вёрстки);
2. от пометки поднимается до карточки — ближайший `li` (или `.Organic`,
   `.serp-item`, `article`), в котором есть ссылка и меньше 4000 символов текста;
3. скрывает карточку: `display: none !important`.

Следит за подгрузкой выдачи и новыми страницами через MutationObserver.

## Проверка

`tests/ad.html` — копия присланной разметки: рекламная карточка (иконка «Промо»),
рекламная карточка с текстовой пометкой и обычный результат.

```bash
npm i jsdom            # в любой временной папке
NODE_PATH=<папка>/node_modules node ads-hider/tests/check.js
```

Ожидаемый вывод: `{"ad1":true,"ad2":true,"organic1":false,"listUntouched":true}`.

## Ограничения

- Скрываются карточки в списке выдачи. Рекламный блок справа и товарные блоки,
  размеченные иначе, не трогаются — для них нужен свой HTML.
- Если Яндекс поменяет `aria-label`, расширение перестанет срабатывать:
  поправить строку `AD_WORD` в `content.js`.
- Свои пометки на других сайтах добавляются в `AD_WORD` + домены в `matches`.
